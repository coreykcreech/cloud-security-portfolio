# Secure Multi-Tier VPC (Terraform)

Status: **in progress**

## Overview
A production-pattern AWS VPC built with Terraform — public, private, and data subnet tiers across multiple Availability Zones, a NAT gateway for outbound-only access from private subnets, tightly scoped security groups, and least-privilege IAM roles.
